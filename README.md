# Fun little OpenGL effects in python

## About the project

This is an experimental python project, where I will create some very simple and fun OpenGL effects, which can be written in very few lines of code.
Nothing fancy and complicated, it is a recreational average late afternoon coding for entertainment.

## Running & Licence

To run the code, you need an installed Python environment with sdl2 and opengl libraries, e.g. on Debian & Ubuntu you can install that by running:
```
sudo apt-get install python3-sdl2 python3-opengl
```
The code is in the public domain.
